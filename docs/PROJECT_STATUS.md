## 项目目标

以中英文官网清楚说明 EasyKiConverter 的实际工作流，展示真实软件界面和可追溯转换证据，引导用户获取当前稳定版；同时保持可访问、响应式、轻量，并将重型 CAD 展示运行时隔离在 3D Lab。

## 当前阶段

项目处于 V0.0.1 稳定维护和持续改进阶段。WEB-01 开始前，`master` 为 `a7b0dbf`，版本分支 `version/V0.0.1` 为 `194768f`；晋级 PR #283 的依赖审查和两次静态站点检查均通过，PR #284 的 `Site Quality` 与 `Dependency Review` 也已通过并合入版本分支。该快照开始时没有待处理的 PR 或 Issue。主项目最新 Release 经 GitHub API 核实为 `v3.1.13`。

当前源码生成 8 个公开路由，Playwright 覆盖桌面/移动 Chromium、双语页面、导航、减少动态效果、Release 数据和 Lab。WEB-01 的当前代码回归为 192 项通过、4 项跳过；构建、站点校验和模型资产检查均通过。GitHub API 限流导致本地 Release 同步返回 403 并使用仓库回退快照；PR #283 的 CI Release 同步及 PR #284 的必需检查均通过。上述证据不等于真实设备测试或生产部署。

## 当前风险与下一步

1. **生产标题尚未同步。** 2026-10-15 对 `https://easykiconverter.org.cn/` 的只读检查显示八个路由均为 HTTP 200，但 `/` 和 `/en/` 各有两个 `<title>`；当前 `master` 已包含唯一标题修复。发布生产站需要项目所有者针对该部署明确批准，本记录不构成部署授权。
2. **继续做用户可感知的内容与风格审查。** 按访客路径核对首页、格式矩阵、案例、Lab、下载页的双语信息层级、术语、CTA 与状态声明；只将证据支持的问题合并为一个聚焦 PR，并附桌面/移动截图。
3. **补齐设备验证。** 自动化 Chromium 检查不能替代真实手机和不同网络条件下的性能、缓存及交互验证；未获得设备证据前保持“未验证”。
